Car Price Prediction using Machine Learning :

📌 Project Overview :
         This project predicts the selling price of used cars using Machine Learning techniques. The dataset was cleaned, analyzed, visualized, and used to train prediction models.
📂 Dataset :
   - Dataset: CAR DETAILS FROM CAR DEKHO
   - Source: Kaggle
   - Records: 4,340
   - Features: Name, Year, Selling Price, KM Driven, Fuel Type, Seller Type, Transmission, Owner

🛠️ Tools & Libraries :
   - Python
   - Google Colab
   - Pandas
   - NumPy
   - Matplotlib
   - Seaborn
   - Scikit-learn
📊 Project Steps :
  1. Imported required libraries
  2. Loaded the dataset
  3. Checked dataset information
  4. Identified null values
  5. Removed duplicate records
  6. Created new features (Car Age and Brand)
  7. Performed Exploratory Data Analysis (EDA)
  8. Encoded categorical features
  9. Generated correlation heatmap
  10. Split the dataset into training and testing sets
  11. Trained Linear Regression and Random Forest models
  12. Compared model performance
  13. Visualized feature importance
🤖 Machine Learning Models :
      - Linear Regression
      - Random Forest Regressor
🔍 Key Findings :
      - Newer cars generally have higher selling prices.
      - Cars with lower mileage usually have higher prices.
      - Random Forest performed better than Linear Regression.
      - Transmission, Brand, KM Driven, Year, and Car Age are the most important features.

## ✅ Conclusion
This project demonstrates how Machine Learning can be used to predict used car prices. Among the two models, Random Forest Regressor achieved better prediction accuracy and proved to be the most effective model for this dataset.
